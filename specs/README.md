# Orbit specs folder

This folder contains planning, design, AI-assisted development evidence, and submission context for the MSA 2026 Phase 2 Software Stream project.

The files are intentionally written as development evidence rather than copied source code. They show how AI was used to plan, debug, test, and refine the Orbit app while keeping implementation decisions understandable.

## Files

- `planning-and-design.md` - product idea, user flow, architecture, and design decisions.
- `ai-prompts.md` - representative prompts used during development, written as concise prompt records rather than full code-generation transcripts.
- `agent-instructions.md` - instructions and constraints used when working with AI assistance.
- `context-and-config.md` - project context, local/deployed environment, API routes, and deployment notes.
- `requirements-checklist.md` - MSA requirement mapping and current readiness status.
